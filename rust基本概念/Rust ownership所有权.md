> [!abstract] 所有权
> Rust通过所有权系统**管理内存**，编译器在编译时会根据一系列的规则进行检查。
> Rust 的所有权可以理解为**编译器强制执行的 unique_ptr 语义**。
> 内存管理分为栈和堆，**栈内存提前分配好，堆内存可变**；
> 语法层面包括：**move、借用、可变借用、Copy**；

## 0.1 核心：每个值只有一个"主人"

> **所有权（ownership）最简单的理解：Rust 里每一个值，在任何时刻都恰好有一个"主人"（owner）。主人负责这个值的一生——尤其是当主人离开作用域时，值被自动释放。**

三条基本原则：
1. **每个值有且仅有一个所有者**（owner）
2. **所有者离开作用域时，值被释放**（drop）
3. **可以借用，但借用要遵守借用规则**

### 0.1.1 所有权的关键概念
- 作用域包括：大括号、函数传参、函数返回值；
- 应当适当使用：move, copy, reference, mute;
- Rust 提供**借用（borrowing）**：`&s` 只是"临时访问权"，`s` 还是主人。

借用分两种：
- `&T`（不可变借用）：**只读**——多个读者可以同时借同一本书
- `&mut T`（可变借用）：**可写**——同一时刻只能有一个人借了书还允许涂改

借用可以将数据竞争消灭在编译期：规则就两条：
1. **同一时刻，要么有任意多个不可变借用（`&`），要么有且仅有一个可变借用（`&mut`），不能混用。**
2. **借用不能比主人活得更久**（防悬垂引用）。

### 0.1.2 三个判断口诀：
1. **要传数据且之后还要用** → 传 `&`（借用）
2. **要传数据且要修改** → 传 `&mut`（且确认没人同时读它）
3. **要传数据且之后不需要了** → 直接传值（move）


### 0.1.3 简单示例

```rust
fn main() {
    let s = String::from("hello");
    // 主人是变量 s，作用域是 main 函数
} // 到这里 s 离开作用域，String 的内存自动释放（drop）
```

这对应 C++ 的 RAII：不需要 `free`、不需要 GC，内存释放是"变量出了作用域"这个事件自动触发的。

## 0.2 为什么需要这套规则？

Rust 的目标是**内存安全 + 无 GC + 无数据竞争**。有三种方式：

| 方案            | 问题                         |
| ------------- | -------------------------- |
| 手动管理（C/C++）   | 忘了释放 = 内存泄漏；释放两次 = 崩溃；悬垂指针 |
| 垃圾回收（Java/Go） | 运行时开销、暂停、不可预测              |
| 编译期解决（Rust）   | 在编译期有严格的规则确定**谁负责谁释放**     |

## 0.3 最佳实践

> [!summary] 示例总结
> 1. **赋值**依据数据类型关于堆栈的使用分为：Move 和 Copy，所有权可能转移
> 2. **函数传参和返回值**会触发move
> 3. **借用**只借不拿，也可以传递**可变借用**

```rust
fn main() {
    // ---------- 1. Move 语义：每个值只有一个所有者 ----------
    let s1 = String::from("hello");
    let s2 = s1;          // s1 的"所有权"移给了 s2（move）
    // println!("{s1}");  // ❌ 取消注释：编译器报错 "value borrowed here after move"
    println!("s2 = {s2}"); // ✅ s2 现在是唯一所有者

    // 对照 C++:
    //   std::unique_ptr<std::string> a = ...;
    //   auto b = std::move(a);   // 需要显式 std::move
    // Rust 中 move 是默认行为，不需要任何关键字

    // ---------- 2. 函数传参也会 move ----------
    let s3 = String::from("world");
    take_ownership(s3);   // s3 的所有权被移进函数
    // println!("{s3}");  // ❌ 取消注释：s3 已经失效

    // ---------- 3. 借用：只"借"不"拿" ----------
    let s4 = String::from("borrow");
    let len = get_len(&s4); // &s4 是借用，s4 仍然拥有数据
    println!("s4 还是我的: {s4}，借用算出的长度: {len}");

    // ---------- 4. 可变借用 &mut：允许修改 ----------
    let mut s5 = String::from("mut");
    push_exclamation(&mut s5); // 可变借用
    println!("修改后: {s5}");

    // ---------- 5. 借用规则：&mut 同一时刻只能有一个 ----------
    // let r1 = &mut s5;
    // let r2 = &mut s5;   // ❌ 取消注释：cannot borrow as mutable more than once
    // println!("{r1} {r2}");

    // ---------- 6. 整数等 Copy 类型例外：复制而非移动 ----------
    let x = 42;
    let y = x;            // i32 实现了 Copy，x 仍然可用！
    println!("x = {x}, y = {y}"); // ✅ 都能用
    // 关键区别：String/Vec 是 move，i32/f64/bool 是 copy
}

fn take_ownership(s: String) {
    // s 拥有传入的 String
    println!("函数内: {s}");
} // 作用域结束，s 被 drop（释放内存）——对应 C++ 的 RAII 析构

fn get_len(s: &String) -> usize {
    s.len() // 借用者只能读，不能改
}

fn push_exclamation(s: &mut String) {
    s.push('!'); // 可变借用者可以改
}
```
