# 推荐的插图使用方式

如果研究内容章节需要控制篇幅，建议优先保留前 **4 张图**：

**图1：Topology-independent Execution State**  
回答：**迁移的对象究竟是什么？**

**图2：Low-pause Consistent Migration**  
回答：**运行中的作业如何安全切换？**

**图3：Cost-aware Migration & Rebinding**  
回答：**哪些状态应该搬、哪些应该重算？**

**图4：Serverless Execution Compaction**  
回答：**这些研究最终如何转化为产品价值？**

第 **5 张图**更适合放在“与现有研究关系及创新点”章节，用来说明：

> **已有研究分别解决 Process Migration、Stream State Migration、Training Migration 和 Dynamic Resource Runtime，而本课题进一步研究 Multimodal Dataflow 的 Online Topology Reshaping。**

这样整套插图就能够形成一个非常完整的研究链路：

**Logical State Abstraction  
→ Consistent Online Migration  
→ Cost-aware State Rebinding  
→ Serverless Execution Compaction**

同时与前面领导汇报中的：

**迁得走 → 迁得稳 → 迁得值 → 产生 Serverless 资源价值**

形成完全一致的叙事结构。
